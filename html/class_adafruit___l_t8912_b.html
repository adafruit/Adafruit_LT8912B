Initialize I2C control and optionally perform a physical reset.

Parameters
wireI2C bus, configured for the board's control pins by the sketch.
resetPinActive-low reset GPIO, or a negative value to leave reset to the caller.
Returns
True when all three fixed addresses (0x48, 0x49, 0x4A) acknowledge.
Note
Checks acknowledgements, not silicon identity. Before begin(), hold the bridge in reset and check 0x48-0x4A for other devices if DDC shares the bus. Isolate DDC only when a monitor device conflicts with a bridge address.

Read the preferred timing from the display's EDID EEPROM at 0x50.

Parameters
timingReceives the decoded timing only on success.
wireI2C bus connected to display DDC; may differ from the bridge bus.
Returns
True if a complete base block contains a supported preferred timing.
Note
Does not require begin(), configure the bridge, or write EEPROM data. When DDC shares the bridge bus, first check for conflicting devices at 0x48-0x4A while holding the bridge in reset before any bridge configuration. Failure leaves timing unchanged so the caller can keep its fallback mode.

Decode the preferred detailed timing from an already-read EDID base block.

Parameters
edidBuffer containing at least one complete 128-byte base block.
lengthNumber of readable bytes in edid; extensions are ignored.
timingReceives the decoded timing only on success; otherwise unchanged.
Returns
True for valid EDID 1.3/1.4 with a preferred progressive digital separate-sync mode, no stereo or borders, and representable bridge sync widths.
Note
Validates the header and checksum. Does not search extension blocks or other descriptors, or check the DSI host's clock, bandwidth, or memory limits. The caller must pass the resulting timing to both the DSI host and bridge; Adafruit_LT8912B_GFX565::begin() does this. VIC and aspect ratio are unspecified.

bool Adafruit_LT8912B::configure ( const LT8912B_Timing &  timing,
uint8_t  lanes = 2 
)

Configure RGB888 DSI reception and enable video-only DVI output.

Parameters
timingSource timing. Active dimensions must be nonzero; sync widths are 1 to 255. Horizontal and vertical totals must each fit in 16 bits. pixelClockMHz must be finite and positive, VIC 0 to 127, and aspectRatio 0 to 2.
lanesNumber of DSI data lanes, 1 to 4, without lane or P/N swapping.
Returns
True on success; false for invalid settings, missing begin(), or I2C failure. A partial I2C failure may require reset() before retrying.
Note
This configures the bridge only. The DSI source must generate matching timing and pixel clock; pixelClockMHz does not program the source clock here. The defaults retain Espressif's 25 MHz reference-crystal initialization.

Read HDMI hot-plug detect from the bridge.

Returns
True if HPD is high, false if low or before begin().
